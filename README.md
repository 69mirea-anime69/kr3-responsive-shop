## Адаптивные решения

На всех страницах задан viewport. `css/responsive.css` подключён после основного `style.css`. За основу взят Mobile First: сначала одна колонка, затем расширение через `min-width`.

- От 600 px карточки идут в две колонки, hero, товар и формы тоже получают две колонки.
- От 900 px навигация располагается в строку, каталог получает боковой фильтр, на главной три карточки в ряд.
- От 1200 px в каталоге три карточки в ряд.
- Flexbox используется в шапке, меню, карточках и подвале; Grid — в каталоге, hero, товаре и формах.
- `minmax(0, 1fr)` и `min-width: 0` не дают содержимому растянуть сетку.
- Изображения имеют `max-width: 100%` и `height: auto`. Для hero добавлен `picture`: до 600 px используется более крупный кадр лампы `lamp-mobile.svg`, выше — полный рисунок. Оба варианта локальные, дополнительных запросов к фотосервисам нет.
- Поля и кнопки имеют размер для удобного нажатия, текст в полях — 16 px. Модальное окно прокручивается внутри экрана.
- Таблица помещена в `.table-wrapper`. Прокрутка разрешена внутри этого блока, сама страница вбок не прокручивается.

## Доступность и доработки

- На каждой странице один h1; сохранена семантическая навигация и подписи полей.
- Добавлена первая ссылка «Перейти к содержимому», видимая при фокусе.
- У текущего пункта меню есть `aria-current="page"`.
- Кнопка меню связана с навигацией через `aria-controls` и сообщает состояние через `aria-expanded`. Escape закрывает меню и возвращает фокус кнопке. Без JavaScript меню остаётся доступным.
- Видимый фокус задан интерактивным элементам. Текст и кнопки контрастны.
- У изображений осмысленные alt; таблица имеет caption и заголовки с scope. Блок таблицы доступен с клавиатуры.
- Нативный dialog удерживает фокус внутри окна; Escape закрывает его, фокус возвращается к исходной кнопке заказа.
- Для результата заполнения формы используется `role="status"`. Форма проверяется браузером, введённые данные не отправляются и не сохраняются.
- `prefers-reduced-motion` отключает плавную прокрутку для пользователей, которым она мешает.

## Проверка

Проверены **все пять страниц** на ширинах **360, 430, 768, 1024 и 1440 px**. Ширина содержимого совпадает с доступной шириной страницы: горизонтального скролла нет. Проверены мобильное меню, Escape, открытие dialog и возврат фокуса после закрытия.

Lighthouse 12, категория Accessibility, локальный HTTP-сервер, 9 ноября 2026 года:

| Страница | Результат | Отчёт |
| --- | --- | --- |
| Главная | 100/100 | [HTML](lighthouse/index.report.html) |
| Каталог | 100/100 | [HTML](lighthouse/catalog.report.html) |
| Заявка | 100/100 | [HTML](lighthouse/order.report.html) |

Отчёты настоящие, получены запуском Lighthouse, JSON-версии также сохранены. Автоматическая оценка не заменяет ручную проверку клавиатурой и на разных экранах.

Для повторной проверки откройте DevTools, задайте указанные ширины и пройдите по всем страницам. Нажимайте Tab и Shift+Tab: фокус должен быть виден. Откройте меню и окно заказа, закройте Escape. На странице товара прокрутите таблицу внутри её блока. В панели Network проверьте, что на узком экране загружается `lamp-mobile.svg`.

## Запуск

Откройте `index.html` или запустите из папки проекта `python -m http.server 8000`, затем перейдите на `http://localhost:8000`. Сборка и установка зависимостей для просмотра не нужны.
